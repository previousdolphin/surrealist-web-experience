Surrealist Web Experience is a one-page art site presenting itself as a dada-inflected exhibition catalogue, pairing a manifesto, a gallery of pure-CSS "light exhibits," an exquisite-corpse phrase collage, visitor testimonials, and a dispatch sign-up form.
